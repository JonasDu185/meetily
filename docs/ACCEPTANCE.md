## 通用要求

- 每项功能有正常路径、失败提示和重复任务防护。
- 未运行的测试明确记录。
- 不泄露录音、转写、密钥和本机隐私数据。
- 回滚不影响已有会议和用户文件。

## 原版构建基线

验收：

- 原版能够启动。
- 完成 5 分钟麦克风与系统声音录制。
- 能停止、保存、转写并重新打开历史会议。

回滚：移除本轮构建产物和测试应用，不修改源码基线。

## 个人隐私基线

验收：

- 使用独立 Bundle ID 和最小独立品牌。
- 不发送 PostHog 请求。
- 不检查或安装 Meetily 官方更新。
- 重启后权限和数据目录保持稳定。

回滚：恢复对应配置文件；保留数据库备份。

## 录音、分轨和导出

验收：

- 同时生成麦克风、系统声音和混合录音。
- 30 分钟录音的三份文件时长和时间基准一致。
- 可以选择位置导出混合录音或全部来源录音。
- 导出失败有明确提示。
- 异常退出后可以恢复检查点。

回滚：保留原混合录音路径，通过功能开关停用新增分轨保存。

## 转写与文本导出

验收：

- 中文实时转写可读，停止后能够补齐最终文本。
- 麦克风和系统轨可分别标记为“我 / 对方”。
- Markdown 为 UTF-8。
- PDF 中文正常、可复制、分页正确且不是截图。

回滚：关闭录后分轨转写，继续使用原混合实时转写。

## 搜索

验收：

- 中文、中英混合、表情符号和长文本搜索不崩溃。
- 可以按标题、日期和正文筛选。
- 点击结果能够定位会议和时间点。

回滚：保留原 SQLite `LIKE` 查询，仅撤回新增筛选或索引。

## 会议检测提醒

验收：

- 常见会议应用进入会议时能够提醒。
- 未经点击确认绝不开始录音。
- 同一会议不会连续重复提醒。
- 已在录音时不会启动第二个录音任务。
- 所有额外权限均说明用途并可关闭。

回滚：使用总开关完全关闭会议检测，手动录音仍可用。

## 长时间稳定性与安装

验收：

- 连续录音至少 2 小时。
- 处理音频设备切换、睡眠唤醒和异常退出。
- 测试蓝牙耳机播放配合 Mac 内置麦克风。
- 单独测试蓝牙耳机同时作为输入和输出，失败时可以切换设备。
- ad-hoc 签名后可安装到 `/Applications` 并重新打开历史。

回滚：移除测试应用，恢复前一份可运行构建；不删除用户会议数据。
